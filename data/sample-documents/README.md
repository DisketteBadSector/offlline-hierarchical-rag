## الزامات مجموعه نمونه

- حداقل ۲ سند از هر قالب (DOC/DOCX/PDF) برای پوشش آزمون واحد ورود.
- حداقل ۱ سند با جدول/تصویر برای مسیر LVM.
- حداقل ۱ سند تکراری/نزدیک‌تکراری برای آزمون تشخیص تکرار.
- حداقل ۱ سند طولانی چندموضوعی برای آزمون خردسازی.
- همه اسناد باید فراداده اولیه (حوزه، گره، مالک، محرمانگی) داشته باشند.
